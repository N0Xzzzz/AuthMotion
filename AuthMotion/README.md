# AuthMotion

A polished, animated login and registration interface for frontend demonstration only.

## Features

- Login, registration, password-reset, and terms-demo views.
- Email, required-field, and confirm-password validation.
- Password visibility toggle and strength feedback.
- Clear validation and success messages with responsive, keyboard-accessible controls.
- No backend, API calls, or storage of entered credentials.

## Technologies

HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
